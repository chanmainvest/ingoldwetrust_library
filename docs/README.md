# In Gold We Trust — Quote Library (static page)

A self-contained static HTML page that reads `quotes.json` from the repo root
and displays random quotes from the *In Gold We Trust* reports, with year
filtering, a themable UI (light / dark), and a paginated top-authors browser.

## Run it locally

The page fetches `../quotes.json` at runtime, so it must be **served over
HTTP** — opening `docs/index.html` directly via `file://` will not work
(browsers block `fetch()` of local files).

From the repo root:

```bash
python -m http.server 8000
```

Then open: <http://localhost:8000/docs/>

Any static server works equally well (`npx serve`, `php -S localhost:8000`,
nginx, GitHub Pages, etc.).

## Features

- **Title bar** with gold-ingot wordmark + light/dark theme toggle (top-right).
  Theme preference and all other settings persist in `localStorage`.
- **Controls**: year filter (narrows the random pool and the author list),
  "how many quotes" (1–50, default 10), and a **New quotes** button to re-roll.
- **Hero quote**: one large featured quote with author, year badge, and chapter.
- **Batch grid**: the remaining N−1 random quotes as cards; click any card to
  promote it to the hero.
- **Top Authors**: ranked by quote count, 10 per page with prev/next pagination
  and page numbers. Click an author to expand and see all their quotes
  (filtered by the current year).

## Data

`quotes.json` is the single source of truth, generated by
`scripts/extract_quotes.py`. Regenerate it whenever `markdown/` changes — the
page will pick up the new data on next load.
